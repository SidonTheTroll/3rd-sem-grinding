## Theory 
The tensile test is the most widely applied of all mechanical tests. In this test, the ends of the test piece are fixed into grips connected to a straining device and to a load-measuring device. If the applied load is small enough, the deformation of any solid body is entirely elastic. An elastically deformed body will return to its original form as soon as the load is removed. However, if the load is too large, the material can be deformed permanently. The initial part of the extension so caused is recoverable immediately after the load is removed and is termed elastic, and the rest of the curve, which represents the manner in which a solid undergoes plastic deformation, is termed plastic. The stress below which the deformation is essentially entirely elastic is known as the yield strength of the material. In some materials, the onset of plastic deformation is denoted by a sudden drop in load, indicating both an upper and a lower yield point. However, some materials do not exhibit a sharp yield point. During plastic deformation at larger extensions, strain hardening cannot compensate for the decrease in cross-section, and thus the load passes through a maximum and then begins to decrease. At this stage, the ultimate tensile strength, which is defined as the ratio of the maximum load on the specimen to the original cross-sectional area, reaches its maximum value. Further loading will eventually cause “neck” formation and rupture.

## Procedure 
1. First, measure the original length and diameter of the specimen. The length may be either the length of the gauge section, which is marked on the specimen, or the entire length of the specimen.
2. Insert the specimen into the grips of the test machine and attach the strain-measuring device to it.
3. Begin the load application and record the load versus elongation data.
4. Take readings more frequently as the yield point is approached.
5. Measure elongation values with the help of a divider and a ruler.
6. Continue the test until fracture occurs.
7. Join the two broken halves of the specimen together and measure the final length and diameter.

## Testing Procedure
Testing of Specimen Through Electronic Control Panel

1. Clamp the specimen between the grips.
2. Start the hydraulic pump and remove the dead weights.
3. On the electronic panel, the following entries are important:
    - **Preload % FS:** This value is a percentage. It is used to start the graph from the zero position. Set it by trial and error (between 0.1 and 1.0%).
    - **Rupture % Peak:** This value is a percentage. It is used to stop the test when the specimen ruptures. Set it by trial and error.
    - **Hold load:** Set this value equal to the capacity of the machine.
4. Enter the above values in the panel and save them, so they need not be entered each time.
5. Press "Start/Stop" twice, then start loading the machine by opening the right-hand valve.
6. At rupture, the test will terminate and the machine will trip off.
7. Connect the dot matrix printer and take a printout.

## Testing of Specimen through PC Software
1. Clamp the specimen between the grips.
2. Start the hydraulic pump and remove the dead weights.
3. In the PC software, first select the required test type, such as "Tension Test". Select the "Create New" option on the toolbar, enter the required initial data, and save the file.
4. Click the "Start Test" button on the toolbar.
5. Enter the required values in the software and click "Data OK". This data will be transferred to the panel.
6. Next, the graph window will appear. Enter the graph scale to view the graph up to rupture, then click the "OK" button.
7. If the load value is not zero, zero it using the "Take Load" button.
8. Click the "Start Test" button to begin loading.
9. At rupture of the specimen, the test will terminate automatically and the machine will stop.
10. The software will then ask for the final gauge length and final diameter (depending on the type of specimen). If required, enter these values from manual measurement.
11. You will then get the load vs. displacement curve and all results.
12. Connect the printer and take a printout.
